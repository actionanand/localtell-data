Privacy and security

  • Codes are generated and decoded locally; no location is sent anywhere unless you open Google Maps or use an online feature.
  • Device location is read only when you press a “Detect” button; there is no background tracking.
  • IP lookup contacts the configured provider only after you confirm the disclosure.
  • Browser storage is not encrypted like Android's private app storage. Anyone with access to this browser profile can read it.
  • .bklt backups are checksummed but not encrypted. Treat them as sensitive location data.
  • Dropbox tokens are kept in session storage (or local storage if you chose to stay signed in) and are never logged or backed up.
  • Map tiles come from {{ tileHost }}, which receives the map areas you view.
